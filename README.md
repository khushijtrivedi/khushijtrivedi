## What I'm Building

### 🌸 Bouquet Visualizer
*In progress — for my own crochet business, [Smriti by You](https://www.instagram.com/smriti_by_you)* · [repo](https://github.com/khushijtrivedi/crochet-bouquet-studio)

Customers kept asking how a single flower would look as a full bouquet. Building a bilingual (English/Hindi) tool with **Next.js + FastAPI** to generate bouquet previews from product photos.

- ✅ Background removal works well using `rembg`, free and local
- 🚧 Stuck on composition — right now the bouquet is built with hand-coded placement and stem drawing, and it looks a bit fake. Looking for a free/low-cost image model that can arrange the flowers more naturally, but most free options are too rate-limited or not good enough yet
